# Roadmap

## v0.1 — included
Event discovery, free reservations, ticket codes, cancellation, event creation, attendee CSV, and organizer check-in.

## v0.2 — authentication and organizer workflows
Independent auth adapter, signup/login, organizations and staff roles, edit/archive events, attendee search, rate limits, unique event routes, explicit timezones, indexes, browser/accessibility tests, and public deployment guidance.

## v0.3 — ticket delivery
Ticket types, individual ticket records for each admission, signed QR tickets, camera scanning, email delivery and resends, accessible PDF tickets. Current check-in admits all people in a booking together.

## v0.4 — paid events
Payment-provider interface, Stripe checkout, verified idempotent webhooks, expiring inventory holds, refunds, promo codes, taxes, fees, and payment reconciliation. No card data should pass through the application.

## Later
PostgreSQL adapter, Docker deployment, admin console, audit logs, advanced analytics, localization, and reusable event branding.
